# Threshold rationale

The primary pair is 500/2000 mL/day. The grid evaluates alternative eligibility definitions.

## No diuretic

The grid uses 400, 500, and 600 mL/day. These values are not universal stopping criteria.

ISCCM guidance identifies spontaneous urine output above 400 mL/day as a useful recovery parameter. The 500 value remains prespecified here. The 600 value tests a more stringent operational definition. [ISCCM guideline](https://pmc.ncbi.nlm.nih.gov/articles/PMC9989875/)

## Diuretic exposure

The grid uses 1000 and 2000 mL/day. The 2000 value defines the primary diuretic-exposed population. The FST trial uses 2000 with diuretics. Its 1000 value concerns spontaneous output. [FST trial](https://pmc.ncbi.nlm.nih.gov/articles/PMC5909278/)

Differences in measurement timing, treatment exposure, and the original study outcome limit direct threshold transfer. Check the underlying study timing when interpreting threshold-specific populations.

A 2026 CRRT conference presentation lists 1000 with diuretics and labels its evidence weak. This provides limited context for the 1000 mL/day threshold. Treat it as exploratory. [Forni presentation](https://www.crrtonline.com/conference/CRRT26_PresPDFs/Forni_20260330__30.03_12.30_Discontinuation_Final.pdf)

## Interpretation

Urine output alone does not establish safe stopping. The model also adjusts for biochemical and fluid information. Clinical conclusions remain conditional on the eligibility rule.

Each pair creates its own time zero, landmark, and target population. Do not interpret a cross-threshold change as pure estimator instability. Do not choose a threshold from favorable significance.
